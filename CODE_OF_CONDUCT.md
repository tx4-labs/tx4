# Code of Conduct

## Purpose

TX4 is a technical infrastructure project. Participation should remain respectful, professional, and focused on improving the software and its community.

## Expected Behavior

* Be respectful and constructive in issues, pull requests, discussions, and reviews.
* Focus critique on ideas, code, and documentation — not on people.
* Assume good faith, and clarify misunderstandings before escalating.
* Respect differing experience levels and communication styles.
* Keep discussions relevant to the project.
* Protect confidentiality of private reports, especially security reports.

## Unacceptable Behavior

* Harassment, discrimination, or personal attacks
* Trolling, insults, or sustained disruption
* Publishing private information without consent
* Posting secrets or sensitive vulnerability details in public channels
* Sexualized language or imagery in project spaces
* Any conduct that would reasonably be considered hostile or unsafe in a professional setting

## Scope

This Code of Conduct applies within project spaces (repository, issues, pull requests, discussions, and related community channels) and when representing the project in public spaces.

## Enforcement

Project maintainers may take actions they deem appropriate, including:

* warning
* editing or removing content
* temporary or permanent restriction from participation
* rejecting contributions

Enforcement decisions should be documented when practical and applied consistently.

## Reporting

Report conduct concerns to the project maintainers through private channels when possible.

If a dedicated conduct contact is not yet published, use the temporary maintainer contact mechanism described in [SECURITY.md](SECURITY.md) for sensitive reports, or open a private maintainer communication path once the project publishes one.

Do not create public issues that include private personal details of others.
